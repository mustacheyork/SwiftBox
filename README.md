# SwiftBox

Swift の文法を 1 テーマ 1 Playground で確かめるためのサンプル集（2022）。
Xcode で `.playground` を開いて、そのまま実行して動きを見る。

| Playground | テーマ |
|---|---|
| Operator | 演算子 |
| TypeConvert | 型変換 |
| TupleType | タプル |
| Collection | 配列・辞書・セット |
| Loop | 繰り返し |
| Functions / FunctionsTraining | 関数と練習問題 |
| Struct | 構造体 |
| ObjectIdentifier | 参照の同一性 |
| DateSample | 日付の扱い |

書籍『iPhoneアプリ開発集中講座』とオンラインスクール CodeCandy の教材を書くときの検証用。
SwiftUI 側のサンプルは [SwiftUIBox](https://github.com/mustacheyork/SwiftUIBox)。
